`askBackend(request)` POSTs to `${env.VITE_API_BASE_URL}/ask` with `Content-Type: application/json`, the JSON-serialized parsed request, and `signal?: AbortSignal` support. Return a discriminated union — never throw for HTTP/network failures:

```ts
type AskResult = { ok: true; answer: string; threadId: string } | { ok: false; kind: AskErrorKind; message: string }
```

`AskErrorKind` = `"network" | "timeout" | "http" | "malformed" | "abort" | "config"`. `message` is always the customer-safe string from `src/lib/errors.ts` (see below). Parse the response body with `askResponseSchema`; a parse failure returns `{ ok: false, kind: "malformed" }`. Non-2xx returns `{ ok: false, kind: "http" }`. Do not attach raw body text, status detail, or stack to the returned message — log those under `if (import.meta.env.DEV)` only (TM-04). Set no `credentials` option: the FastAPI CORS config in `../main.py` is `allow_origins: ["*"]` with `allow_credentials: false`, so cookie-based auth against the backend is impossible by design.

`src/lib/errors.ts` exports the `AskErrorKind` union, the `AskResult` type, and a `CUSTOMER_MESSAGES: Record<AskErrorKind, string>` map with one generic sentence per kind. No raw diagnostics in any value.

`src/lib/env.ts` exports `publicEnvSchema = z.strictObject({ VITE_API_BASE_URL: z.string().url(), VITE_CONVEX_URL: z.string().url() })` and `env` = the parsed `import.meta.env` subset.
