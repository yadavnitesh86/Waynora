## Phase Goal

**As a** traveler waiting for a long AI trip generation, **I want** to play a responsive, accessible game of 2048, **so that** the waiting time feels engaging without breaking my focus or interfering with the chat request.

<objective>
Implement the deterministic 2048 game engine and accessible React components featuring keyboard and touch gesture navigation, score tracking, win/game-over overlays, and strict input isolation.
</objective>

<tasks>
### Task 1: Pure Deterministic 2048 Game Engine (`src/lib/game/2048/`)
- Create `types.ts`:
  - `Direction = 'UP' | 'DOWN' | 'LEFT' | 'RIGHT'`
  - `Tile = { id: string; value: number; row: number; col: number; merged?: boolean }`
  - `Grid = (Tile | null)[][]` (4x4)
  - `GameState = { grid: Grid; score: number; bestScore: number; won: boolean; gameOver: boolean; moved: boolean }`
- Create `engine.ts`:
  - Pure slide and merge algorithm for all 4 directions
  - Score accumulation matching standard 2048 rules
  - `canMove(grid)`: checks for any empty cells or adjacent identical tiles
  - `hasWon(grid)`: checks if any tile value equals 2048
  - `spawnRandomTile(grid, rng?)`: deterministic tile spawner (90% 2, 10% 4) supporting seeded injection for testing
- Comprehensive unit tests in `engine.test.ts` verifying slide, merge, cascades, score calculations, win condition, and game-over detection.

### Task 2: Accessible Board, Tiles, and Game Overlays (`GameBoard`, `Tile`)
- Create `src/components/game/Tile.tsx`:
  - Displays tile value with distinctive color tokens based on value
  - Respects reduced motion preferences (`prefers-reduced-motion`)
- Create `src/components/game/GameBoard.tsx`:
  - Renders 4x4 grid cells with proper ARIA grid/cell roles
  - Renders overlay banners for "You Win!" (with "Keep Going" / "New Game") and "Game Over" (with "Try Again")

### Task 3: Interactive Controller & Device-Adaptive Input Isolation (`Game2048.tsx`)
- Create `src/components/game/Game2048.tsx`:
  - Score board showing Current Score and Best Score (persisted in localStorage / session)
  - **Desktop Controls**:
    - Keyboard event listener for Arrow keys (ArrowUp, ArrowDown, ArrowLeft, ArrowRight) and WASD
    - Only responds when game board container is focused or active
    - Ignores keystrokes if `document.activeElement` is an `input` or `textarea` (GAME-06)
    - Calls `event.preventDefault()` only on handled game keys when game board is active
    - Visible desktop keyboard hint banner ("Use arrow keys or WASD to move tiles")
  - **Mobile / Touch Controls**:
    - Touch/pointer gesture listener: calculates swipe direction on touchstart/touchend
    - Container styled with `touch-action: none` on the board to prevent scroll-jacking mobile viewports
    - On-screen touch controls: renders an accessible touch-friendly directional pad / buttons (Up, Down, Left, Right) on mobile/touch viewports (`sm:hidden` or touch-detected) for comfortable single-hand/thumb tap interaction
    - Clear mobile instruction banner ("Swipe or tap arrows to move tiles")
  - Unit and interaction tests in `Game2048.test.tsx` verifying keyboard navigation on desktop, touch swipes and on-screen directional buttons on mobile, focus containment, and ARIA labels.
</tasks>
