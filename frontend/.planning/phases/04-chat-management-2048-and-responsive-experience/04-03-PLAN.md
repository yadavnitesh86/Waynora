## Phase Goal

**As a** traveler, **I want** the 2048 game to appear during long waits without obscuring generation progress, and **I want** the entire interface to function smoothly on my phone, tablet, and desktop.

<objective>
Integrate the 2048 waiting game directly into the active waiting lifecycle (`WaitingShell`), ensure zero interference with request resolution, polish cross-device responsive behavior, and verify accessibility and contract invariants across the phase.
</objective>

<tasks>
### Task 1: Integrate 2048 Game into `WaitingShell`
- Update `src/components/chat/WaitingShell.tsx`:
  - Conditionally render `Game2048` inside a dedicated "Waiting Lounge / Pass the Time" collapsible card or side-by-side section
  - Ensure elapsed timer (M:SS), band copy, and "Stop waiting" button remain visible and accessible alongside the game
  - Verify that when the request status changes from `waiting` to `succeeded` or `failed`, the shell unmounts cleanly and preserves the response
- Update `src/components/chat/WaitingShell.test.tsx` verifying:
  - Game is present only when `status === 'waiting'`
  - Timer continues ticking regardless of game moves
  - Clicking "Stop waiting" triggers abort handler without game interference

### Task 2: Responsive Polish & Layout Refinement (Mobile, Tablet, Desktop)
- Refine responsive breakpoints in `Chat.tsx`, `ChatSidebar.tsx`, and `WaitingShell.tsx`:
  - Mobile (<640px): Sidebar as drawer overlay with backdrop, compact waiting game board scaled to fit small viewports, composer sticky to bottom
  - Tablet (640px–1024px): Collapsible icon-or-compact sidebar, centered chat column
  - Desktop (>1024px): Two-column layout with sidebar and wide chat stream
- Support `prefers-reduced-motion` for transitions and game tile sliding animations.
- Create `src/routes/Chat.responsive.test.tsx` checking layout classes, mobile drawer toggle, and viewport adaptability.

### Task 3: Comprehensive Verification & Accessibility Audit
- Update `src/test/a11y.test.tsx`:
  - Run `axe` checks against sidebar, active waiting room with 2048, empty states, and modal overlays
  - Verify zero axe violations (contrast, landmark structure, accessible names)
- Run full test suite (`pnpm test` or `vitest run`) and typecheck (`tsc --noEmit`).
</tasks>
