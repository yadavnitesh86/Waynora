## Phase Goal

**As a** traveler, **I want** to browse, organize, rename, delete, and switch between my saved travel planning chats, **so that** I can easily manage multiple trip itineraries across sessions.

<objective>
Build the multi-conversation chat management layer: the `useConversations` hook connecting in-memory state to the cookie repository, the accessible `ChatSidebar` and `ConversationItem` components with inline rename and delete controls, and integrate them into `Chat.tsx` with a responsive drawer pattern.
</objective>

<tasks>
### Task 1: Conversation Management Hook (`useConversations`)
- Create `src/hooks/useConversations.ts` providing:
  - `conversations`: Conversation[] sorted newest first
  - `activeId`: string | null
  - `activeConversation`: Conversation | null
  - `createConversation()`: creates and activates a new empty conversation
  - `selectConversation(id)`: activates the selected conversation
  - `renameConversation(id, newTitle)`: updates title and saves to cookie repository
  - `deleteConversation(id)`: deletes conversation, safely updates activeId to the next available conversation
  - `syncConversation(updated)`: updates active conversation messages and derives auto-title on first message
- Unit test in `src/hooks/useConversations.test.ts` with mocked cookie repository covering CRUD and edge cases.

### Task 2: Accessible Sidebar & Conversation Items (`ChatSidebar`, `ConversationItem`)
- Create `src/components/chat/ConversationItem.tsx`:
  - Renders title, formatted date/time, active highlight
  - Inline rename edit mode (Enter saves, Esc cancels, input validation)
  - Delete action button with accessible confirmation
- Create `src/components/chat/ChatSidebar.tsx`:
  - "New Chat" primary action button
  - Scrollable list of conversations with empty state when no chats exist
  - Mobile drawer toggle (open/close overlay) and desktop collapsible sidebar
  - Proper ARIA landmarks (`<nav aria-label="Chat history">`) and keyboard focus navigation
- Unit tests in `ConversationItem.test.tsx` and `ChatSidebar.test.tsx`.

### Task 3: Integration into `Chat.tsx` Route & Responsive Layout
- Update `src/routes/Chat.tsx`:
  - Wire `useConversations` into the page
  - Render `ChatSidebar` alongside `ChatThread` and `ChatComposer` in a responsive flex/grid layout
  - Mobile hamburger toggle in header to open/close sidebar drawer
  - Ensure switching chats properly cleans up active request controller if in-flight
- Update `src/routes/Chat.test.tsx` verifying:
  - Switching conversation updates rendered thread
  - Creating new chat resets thread to empty composer state
  - Renaming and deleting persist across simulated reload
</tasks>
